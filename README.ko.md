# User-Hopper
> 제조사가 멀티유저 기능을 차단한 안드로이드 기기에서 게스트 모드를 활성화 하거나 '디지털 유산' 기능으로 우회하여 활성화 합니다.

[English](./README.md) · [한국어](./README.ko.md)

---
> [Shizuku](https://shizuku.rikka.app/)를 통해 루팅 없이 멀티 유저 환경을 생성합니다.

### 모드
|       | 게스트 모드                                 | 디지털 유산 모드              |
|-------|----------------------------------------|------------------------|
| 지원 대상 | 일반적인 안드로이드 기기 혹은 One UI 8.0 이하의 갤럭시 기기 | One UI 7.0 이상의 갤럭시 기기  |
| 생성 방식 | 앱이 직접 생성 (`pm create-user --guest`)    | 삼성 디지털 유산 기능으로 우회하여 생성 |

### 기능
- 보조 사용자 생성, 시작, 종료, 삭제
- 사용자를 삭제하지 않고 세션 종료 (보조 사용자에서 실행 중인 앱 모두 종료)
- 디지털 유산 사용자를 자동 감지하고 Shizuku와 User-Hopper를 자동 설치

### 요구사항
- [Shizuku](https://shizuku.rikka.app/)
- 디지털 유산을 지원하는 삼성 One UI 7.0 이상의 기기 (선택 사항이며, One UI 8.5 이상의 기기에서는 필수)

### 사용법
**게스트 모드**
1. Shizuku 서비스를 시작하고 User-Hopper를 열어 Shizuku 권한을 허용
2. **게스트 사용자 생성**을 눌러 게스트 사용자 생성
3. **Shizuku 앱 설치**, **매니저 앱 설치**를 순서대로 눌러서 설치
4. **게스트 시작** 버튼으로 사용자 전환
5. **게스트 종료** 버튼으로 소유자로 전환

**디지털 유산 모드**
1. Shizuku 서비스를 시작하고 User-Hopper를 열어 Shizuku 권한을 허용
2. **디지털 유산 사용자 생성**을 눌러 디지털 유산 애플리케이션 속성에 진입
3. 상당의 **디지털 유산 설정**을 누른 후, 아래의 **디지털 유산 요청**을 눌러 사용자 생성 및 전환
4. **디지털 유산 종료** 버튼으로 소유자로 전환

### 주의사항
#### 공통
- **보조 사용자에 갇힐 수 있습니다.** 일반적으로 지원되지 않는 기기에서 보조 사용자로 이동 후 Shizuku 서비스가 중단 되는 경우, 혹은 앱을 삭제할 경우 소유자로 전환하지 못 할 수 있습니다. 해당 사용자 안에서 Shizuku 서비스에 연결 중이고 User-Hopper에 Shizuku 권한이 있는지 확인하세요. 중단 된 경우, USB 디버깅으로 전환 해야 하거나 기기를 재시작 해야 합니다. (소유자의 저장되지 않은 데이터를 잃게 됩니다)
- 사용에 따른 책임은 본인에게 있습니다. 이 프로젝트는 삼성 및 구글과 관련이 없습니다.

#### 게스트
- 게스트로 전환 후 시스템에서 세션을 초기화 여부에 대해 묻는다면 **절대 초기화를 하지 마세요.** 초기화를 진행 할 경우, 게스트에 있는 Shizuku와 매니저 앱이 사라져, 기본적으로 전환 토글이 없는 기기에서 상술한 문제처럼 갇히게 될 수 있습니다.

#### 디지털 유산
- **디지털 유산 기능이 정말로 필요하지 않은 경우에만 사용하세요.** 본래 이 기능은 고인의 삼성 클라우드에 저장된 연락처, 노트 등의 휴대전화 대이터를 고인이 생전에 지정한 유산 관리자에게 안전하게 전달하는 기능입니다. 정말로 필요하게 된다면 디지털 유산 사용자를 삭제 후, 설정에서 직접 유산을 요청하세요.
- 매니저 앱이 아닌 설정에서 직접 디지털 유산 요청을 눌러 실행할 경우에는 정상적인 디지털 유산 화면으로 전환됩니다. 매니저 앱에서 시작할 경우, 디지털 유산 사용자의 디지털 유산 기능을 비활성화 하여 일반적인 보조 사용자처럼 사용할 수 있습니다.
- 삼성 갤럭시의 태블릿과, 타사의 기기에서는 사용할 수 없습니다.


### 동작 원리
User-Hopper는 Shizuku를 통해 표준 Android 셸 명령을 실행합니다.

| 동작                  | 명령 (shell)                                              |
|---------------------|---------------------------------------------------------|
| 게스트 사용자 생성          | `pm create-user --guest Guest`                          |
| 사용자에 앱 설치           | `pm install-existing --user <id> <package>`             |
| 시작 / Exit           | `am switch-user <id>`                                   |
| 세션 종료               | `am stop-user -w -f <id>`                               |
| 사용자 삭제              | `pm remove-user <id>`                                   |
| 디지털 유산 앱 활성화 / 비활성화 | `pm disable-user --user <id>` / `pm enable --user <id>` |
| 사용자·세션 감지           | `pm list users`                                         |

### 문제 해결
- **버튼이 회색으로 비활성화된 경우**: 지금 상황에 사용할 수 없는 동작입니다. 이미 게스트 혹은 디지털 유산 사용자에서 실행 중일 경우 시작 버튼이 꺼집니다. 뭔가 잘 못 된것 같다면 오른쪽 상단의 새로고침 버튼을 눌러보세요.
- **Shizuku 오류**: Shizuku가 실행 중이고 권한이 허용됐는지 확인하세요. 실패한 명령은 `<디바이스 저장공간>/Documents/UserHopper/command_log.txt`에서 볼 수 있습니다.
- **보조 사용자 안에서 Exit가 비활성화됨**: 그 사용자에서 Shizuku가 실행되지 않았거나 권한이 없는 상태입니다.
